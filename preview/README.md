# モグモグガチャ：独立プレビュー準備

このブランチは本番の main とは分離されたガチャ演出の検証用です。GitHub Pages の公開元を変更しない限り、このブランチのファイルは本番サイトに反映されません。

## 変更してはいけないもの
- 承認済みの木製外枠、ヘッダー、フッター、ボタン配置、iPhone/iPadレイアウト
- Firestore/Auth/本番ガチャの抽選・コイン・チケット処理

## 内部演出の目標
- 画像パーツでアーム・タマゴを独立アニメーション
- 掴むまで共通、掴んだ後に通常（N/R）、チャンス（SR/SSR）、激アツ（UR）に分岐
- タマゴの発光、孵化、カード登場、音を同期
- 開発用プレビューはDB接続なし

## 状況
プレビュー用ブランチの分離を完了。承認済みフレームを維持したHTML・画像アセットのGitHubへの配置と、公開URLの実機確認は未完了。プレビューURLを完成扱いで案内しないこと。
